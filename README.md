# Geodynamic Model Visualization

This repository contains Python scripts for visualization of results from a geodynamic model simulating the evolution of a continental lithosphere from rifting to convergence. The modeled scenario includes continental extension and breakup, formation of oceanic lithosphere, subsequent convergence, subduction, and continental collision.

The repository provides tools for generating time-dependent maps and animations from model outputs, allowing visualization of the spatial evolution of key rheological and deformation parameters throughout the simulation.

## Scripts

### Viscosity Evolution Visualization

Processes viscosity data (Pa·s) and generates high-resolution maps and MP4 animations showing the evolution of the viscosity field through geological time.

### Bulk Strain Evolution Visualization

Processes bulk strain data (dimensionless strain) and generates maps and MP4 animations illustrating the accumulation and distribution of deformation during model evolution.

Both scripts use time-series outputs from the same geodynamic model and are intended for efficient visualization and presentation of simulation results.
